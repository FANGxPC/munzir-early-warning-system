## Slide 9: Risks and Safeguards*

### 1. Privacy Safeguards
* **Zero-PII Analytics:** Individual identity records never enter the analytics lakehouse.
* **Small-Cell Suppression ($k \ge 50$):** Any cell, cluster, or query containing fewer than 50 workers is automatically masked to prevent re-identification.
* **Differential Privacy:** Public community releases are protected via Laplace Differential Privacy ($\varepsilon = 1.0$) calibrated using Harvard's OpenDP library.

### 2. Security Safeguards
* **Zero-Trust RBAC:** Role-Based Access Control enforced via Azure Entra ID across 6 segregated application roles.
* **Cryptographic Transit & Storage:** TLS 1.3 transit encryption; AES-256 encrypted Parquet lakehouse storage with daily key rotation.

### 3. Bias Elimination
* **Race-Free Clinical Equations:** Replaces biased ethnic multipliers with the validated 2021 CKD-EPI equation.
* **Demographic Parity:** Regular algorithmic audits ensure equitable protection across all nationalities, ages, and worker categories.

### 4. Explainability & Interpretability
* **Dual-Tier Interpretability:** Every alert features TreeSHAP waterfall charts explaining exact machine learning feature contributions, paired with plain-language epidemiological indicator cards.

### 5. Worker Protection Against Misuse (Safe-Harbor Shield)
* **Cryptographic Safe-Harbor Worker Shield:** If an employer attempts to query individual worker break durations, bathroom visits, or attendance for disciplinary purposes, the platform triggers an immediate **hard HTTP 403 Forbidden** block and files an immutable security audit alert, enforcing **UAE Federal Decree-Law No. 33 of 2021 (Article 13)**.

### 6. Human Oversight (Human-in-the-Loop)
* **Advisory Boundary:** Munzir generates prioritized operational recommendations and evidence cards, but legal work-stoppage orders, municipal dispatch, and clinical triage require explicit sign-off by accredited officers.

### 7. Failure Modes & Graceful Degradation
* **Data Dropout Resilience:** If physical IoT sensors fail or lose connectivity, the platform automatically falls back to satellite H3 grid data, widens its conformal prediction bands (90% CI), and alerts commanders to the missing sensor input.
